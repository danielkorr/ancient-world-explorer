# AWE Codex Handoff — ARGO + Pleiades Photo Quest

**Target:** Existing Ancient World Explorer (AWE) repository, executed in OpenAI Codex inside PyCharm.

## Quick start
1. Save/extract this package into your AWE repository (suggested location `docs/handoffs/argo-pleiades/`).
2. Open the existing AWE repository in PyCharm and launch Codex with the repository as its working directory.
3. Paste the contents of `CODEX_PROMPT.md` into Codex. Do not start a new application.
4. Have Codex inspect the actual codebase, existing Research Lab/Photo Quest features, deployment, and tests before modifying anything.
5. Review the plan and diff; run local tests; confirm external links, mobile layout, credits, license display, and existing behavior before committing/deploying.

## Files
- `CODEX_PROMPT.md` — ready-to-paste execution brief.
- `REQUIREMENTS.md` — approved product decisions, evidence URLs, phased implementation, acceptance tests, licensing and provenance rules.

## Important
Pleiades is an **external scholarly contributor destination**, not an AWE-owned image review service. AWE must not represent Flickr tagging or group acceptance as scholarly authentication. No automatic photo submission to Pleiades or Flickr is authorized.
